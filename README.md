# VibeControl

Проект представляет собой консольный тестер вибрации для геймпада с использованием библиотеки `pygame`. Скрипт инициализирует первый доступный джойстик, проверяет поддержку вибрации и позволяет запускать различные режимы виброотклика через кнопки и триггеры контроллера.

### 1. Структура проекта

```text
├─ VibeControl.py
└─ README.md
```

### 2. Описание файлов

#### `VibeControl.py`
- **Назначение**: Управление вибрацией геймпада, обработка ввода кнопок/триггеров, запуск тестовых режимов вибрации.
- **Ключевые функции/классы**:
  - `class GamepadVibrateTest`: основной контроллер.
    - `__init__()`: инициализация `pygame`, `joystick`, проверка поддержки вибрации.
    - `show_menu()`: заглушка (без вывода).
    - Режимы вибрации: `vibrate_short`, `vibrate_long`, `vibrate_pulse`, `vibrate_wave`, `vibrate_weak`, `vibrate_strong`, `vibrate_variable`.
    - Служебные: `test_all_modes`, `handle_button_press`, `run`.
  - `main()`: точка входа; создаёт `GamepadVibrateTest` и запускает `run()`.
- **Связи с другими файлами**: отсутствуют; модуль автономен.
- **Краткая логика**: При старте инициализируется `pygame` и первый джойстик. Если найдён и поддерживает вибрацию, запускается цикл `run`, который опрашивает события, читает кнопки и триггеры, а затем вызывает соответствующие режимы вибрации. Часть режимов работает в фоновых потоках, чтобы не блокировать основной цикл.

- **Назначение**: Документация проекта.
- **Ключевые функции/классы**: нет.
- **Связи**: описывает `VibeControl.py`.
- **Краткая логика**: справочные материалы по использованию и архитектуре.

### 3. Архитектура проекта

- **Общая структура**: одиночный модуль с одним классом, инкапсулирующим жизненный цикл приложения и работу с геймпадом. Взаимодействие с устройством идёт через `pygame.joystick`.
- **Потоки данных**:
  - Ввод: кнопки и триггеры геймпада через `pygame.event.pump()` и API `joystick`.
  - Обработка: сопоставление кнопок режимам вибрации, вычисление интенсивности (в т.ч. синусоида).
  - Вывод: вызовы `joystick.rumble(left, right, duration_ms)`.

### 4. Библиотеки/фреймворки

- **pygame**: работа с джойстиками, событиями и вибрацией (`pygame.init`, `pygame.joystick.*`, `Joystick.rumble`, `event.pump`, `time.Clock`).
- **time**: задержки в шаблонах вибрации (`sleep`).
- **threading**: фоновое выполнение сложных шаблонов вибрации без блокировки основного цикла.
- **math**: вычисление синусоидальной огибающей интенсивности в `vibrate_wave`.

### 5. Точка входа и запуск

- **Точка входа**: блок `if __name__ == "__main__": main()` в `VibeControl.py`.
- **Как запускать**:

```bash
python VibeControl.py
```

- **Предусловия**:
  - Установлена библиотека `pygame`.
  - Подключён геймпад с поддержкой вибрации (rumble).

```bash
pip install pygame
```

- **Что выполняется первым**: инициализация `pygame` и подсистемы `joystick`, выбор первого доступного устройства, проверка поддержки вибрации.

### 6. Архитектурные особенности

- **Отсутствие консольного вывода**: скрипт работает бесшумно; все `print` удалены, поведение индицируется только вибрацией.
- **Неблокирующие шаблоны вибрации**: режимы с временными паттернами запускаются в отдельных потоках, основной цикл остаётся отзывчивым.
- **Прямая карта кнопок → действия**: кнопки 0–7 сопоставлены режимам вибрации и выходу; триггеры (оси 4/5) управляют интенсивностью в реальном времени.
- **Без внешней конфигурации/GUI**: простота развёртывания, минимум зависимостей.

### Приложение: Быстрая сводка режимов

- Кнопка 0: короткая вибрация
- Кнопка 1: длинная вибрация
- Кнопка 2: волна (синусоидальная)
- Кнопка 3: пульс
- Кнопка 4: слабая
- Кнопка 5: сильная
- Кнопка 6: последовательный тест всех режимов

- Кнопка 7: выход (останавливает цикл)
